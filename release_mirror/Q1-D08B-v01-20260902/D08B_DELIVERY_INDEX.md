## Integrity-file convention

The table above indexes every payload file present before the integrity trio is written. `MANIFEST.json` then indexes the payload plus this delivery index. `SHA256SUMS.csv` indexes the payload, this index, and the manifest. The checksum list does not hash itself, avoiding circular metadata. The outer ZIP sidecar validates the complete packaged directory, including all three integrity files.

## Mainline boundary

This package is for independent scientific-mainline audit only. It contains no final species selection and authorizes no D08C, FIA TREE merge, Little-layer merge, or real-Q1 analysis.
